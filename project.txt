API KEY PROTECTION – TEAM INSTRUCTIONS
Every team member must follow these steps when setting up an API key for this project.
1. Open the Early_Enlightenment project in Android Studio.
2. In the main project folder, create a new file named API_KEY.txt.
3. Open the file and enter your API key. Keep your actual key private.
4. Open the .gitignore file in the main project folder.
5. Add the following line if it is not already there:
API_KEY.txt
6. Save the .gitignore file.
7. Open the Terminal in Android Studio and run:
git check-ignore -v API_KEY.txt
8. Make sure Git recognizes the file as ignored.
9. Check the Commit window to make sure API_KEY.txt does not appear as a file to upload.
IMPORTANT:
• Never commit or push your API_KEY.txt file to GitHub.
• Never share your API key with other people.
• Do not put API keys directly into your source code.
• Each team member should keep their own API key file on their computer.
• If an API key is accidentally uploaded to GitHub, revoke it and generate a new one.
The .gitignore file is already included in the project, so team members should not need to add the API_KEY.txt rule again.
